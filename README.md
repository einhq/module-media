# module-media

Renditions of pictures, videos and recordings, and what describes a file, for any module: the
media pool's workers that run that work, and in time the reading of a file, its renditions, its
picture vectors, the text in it and its transcripts.

An [EiN](https://github.com/einhq) module. It is developed and tested inside a checkout of EiN core,
as `modules/media`, and a deployment chooses whether to run it.
